VERVIEW

Project Overview

RUBLING is a robotic Rubik’s Cube mural system designed to physically generate predefined visual patterns using an electromechanical cube manipulation platform. Rather than focusing on optimal or fully general cube solving, this project emphasizes reliable execution, repeatability, and clear coordination between software, electronics, and mechanical subsystems.

The system accepts user-selected patterns and autonomously performs the corresponding sequence of cube face rotations to produce recognizable designs. This approach allows the system to function as a robust demonstration platform while remaining within realistic budget, time, and integration constraints.

Project Objectives

The primary objective of this project was to design and build an integrated robotic system capable of reliably transforming a Rubik’s Cube into predefined patterns without manual intervention. Achieving this required careful balancing of mechanical design, electrical control, and software coordination.

Additional objectives included minimizing mechanical failure modes, maintaining deterministic system behavior, and creating a user-facing interface that allows patterns to be selected and executed consistently during live demonstrations.

Final System Demonstration

The final system consists of a motorized frame that engages five faces of a Rubik’s Cube using stepper motors and custom mounts. A Raspberry Pi serves as the central controller, coordinating communication between the user interface and multiple Arduino microcontrollers responsible for motor execution.

During a demonstration, a user selects a target pattern through the software interface. The system then executes a precomputed sequence of cube rotations, transmitting synchronized commands to the hardware layer. This process produces consistent visual results across repeated runs and highlights the system’s emphasis on reliability and predictability.

Design Process Summary

The design process followed an iterative and constraint-driven approach, with mechanical, electrical, and software decisions evolving together through prototyping and testing. Early concepts explored real-time solving and vision- based feedback, but these approaches were scaled back as their complexity and integration risk became apparent.

Through successive iterations, the team prioritized solutions that reduced system fragility and improved repeatability. The final design reflects these trade-offs, resulting in a system that is well-suited for demonstration, maintainable within the project timeline, and clearly communicates the engineering decisions behind its construction.
